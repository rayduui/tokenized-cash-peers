# RWA Pulse

Next.js dashboard for tokenized funds and real-world assets across markets.

## Data
- Live protocol AUM / change / chain counts from DefiLlama free `/protocols` endpoint.
- Official 7-day yields for major funds maintained in the component (can be moved to a JSON or CMS).

## Deploy
Push to `main` → Vercel auto-deploys.

Live: https://rwa-pulse-live.vercel.app
